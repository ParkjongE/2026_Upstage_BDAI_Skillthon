# 패션의류 분석 예시

## 요청 예시

```
패션의류 검색 관심도 급증이 실제 수요 신호인지 봐줘.
```

## 실행 명령

```
python scripts/run_pipeline.py --category fashion_apparel --period-months 48
```

## 기대 실행 흐름

1. `reference/category-mapping.md`에서 `fashion_apparel` 확인
2. 네이버 `패션의류 / 50000000`과 통계청 `의복` 데이터 로드
3. 월 기준 조인 후 매칭률 로그 출력
4. 검색지수 잔차 기준 이상 이벤트 탐지
5. 후행 1-2개월 거래액 반응으로 과거 이벤트 라벨링
6. 표본이 충분하면 등급형 판정, 부족하면 판단 보류
7. 웹 리포트 저장

## 표현 제약

"관심 있게 지켜볼 만함", "모호함, 추가 관찰 필요", "반짝 관심(노이즈)일
가능성 높음", "판단 보류"처럼 등급형 표현을 사용한다. 카테고리가 확실히
오르거나 내린다고 말하지 않는다.
