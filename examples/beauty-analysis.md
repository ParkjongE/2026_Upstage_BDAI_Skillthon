# 화장품/미용 분석 예시

## 요청 예시

```
화장품/미용 카테고리 검색 증가가 반짝 관심인지 실제 수요 신호인지 분석해줘.
```

## 실행 명령

```
python scripts/run_pipeline.py --category beauty --period-months 48
```

## 기대 산출물

- `data/` 아래에 웹 리포트 1개
- 리포트 상단의 데이터 출처 표시
- 이상 이벤트 발생 월과 과거 라벨이 포함된 근거 목록
- 표본 수 설명
- 네이버 상대지수, 통계청 월별 거래액, 관측 단위 차이, 최근 통계청 잠정치
  가능성에 대한 한계 문단

## 대체 데이터 동작

`KOSIS_API_KEY` 또는 네이버 인증 정보가 없으면 재현 가능한 데모 데이터를
사용하고, 정확한 대체 사유를 리포트에 표시한다.
